# Практическая работа №1.1 — Первая модель

## Запуск

Необходимы Node.js и npm. В терминале в папке проекта выполните:

```sh
npm install
npm start
```

## Поля модели

| Поле | Тип Sequelize | Ограничения и назначение |
| --- | --- | --- |
| firstName | STRING | Обязательное непустое имя |
| lastName | STRING | Фамилия, необязательное поле |
| email | STRING | Обязательный уникальный email, проверка формата |
| age | INTEGER | Обязательное целое число от 0 до 120 |
